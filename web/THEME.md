# دليل الأنماط والثيمات المعتمدة (Gate-Payroll 1.0 Design System)

تم اعتماد نظام الألوان وفق قرار 2026-11-02 وقواعد `antigravity.md` ومطابقة معايير إتاحة الوصول WCAG AA:
- **الثيم الافتراضي (`sand`):** رملي دافئ (Mid warm beige)، مريح للعين طوال اليوم.
- **الثيم الفاتح (`light`):** بيج فاتح دافئ (Light beige)، بدون برودة الرصاصي.
- **الثيم الداكن (`dim`):** داكن هادئ مستوحى من VS Code / GitHub dark، متباين ومريح للرؤية الليلية.

## قواعد الطباعة والاتجاه
1. الاتجاه العام: `dir="rtl"` ولغة الواجهة `lang="ar"`.
2. خط الواجهة: خط Cairo المحفوظ محلياً في `public/fonts/cairo.ttf` عبر `@font-face` بدون أي اعتماد على CDN خارجي.
3. الأرقام والحسابات: استخدام الفئة `.num` لفرض `direction: ltr` و`font-variant-numeric: tabular-nums` لثبات المحاذاة.
