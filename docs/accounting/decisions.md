## أسئلة تحتاج قرارًا أو تنفيذًا

| السؤال | الوضع الحالي | ما يلزم قبل التغيير |
|---|---|---|
| ما مقابل افتتاح عهدة/نقدية جاهز؟ | `3101` حتى لحسابات `SUP.*.SET/MAIN.*.SET/BANK.*.JAHEZ` | قرار المالك: التزام `2140` أو تسوية `1240` أو اختيار موثق لكل صف؛ المراجعة ذكرت `2110` أيضًا عند وجود مستحق رواتب. لا اختيار تلقائي ولا افتراض أن النقدية ملكية للشركة |
| من يُمنح `treasury.opening`؟ | دور Accountant لا يكفي وحده لالتزام استيراد الافتتاح | تحديد المعتمد: FinancialManager/Admin أو مستخدم مفوض؛ لا توسيع صلاحيات ضمن التوثيق |
| كيف تحرر عمولة `4102` من أموال التسوية؟ | رواتب نفس الشركة أصبحت ممكنة؛ العمولة لا تزال محجوزة في مسار التسوية | مسار بحد المكتسب ناقص التحريرات السابقة ودليل واعتماد مستقل |
| كيف تقاص مستحقات جاهز؟ | استقبال `1240` وسداد `2140` بنكيًا منفصلان | حدث Dr `2140` / Cr `1240` من كشف المنصة، لنفس الشركة وبحد الحق والالتزام |
| كيف تصحح الأخطاء والتصنيفات التاريخية؟ | لا عكس مستندات أو إقفال فترات | بناء العكس المرتبط بالأصل وضبط الفترة أولًا؛ ثم إعادة تصنيف مراجعة بقيود فقط |
| ما حد الإعفاء الذي يحتاج معتمدًا ثانيًا؟ وهل كل نقل دين يحتاجه؟ | إذن وسبب دون مسار قرار ثانٍ كامل | حد مالي وصلاحيات وفصل مهام يقرها المالك، مع تقرير إدارة وحدود استعمال |
| Payroll أم ERP هو دفتر المرجع للخزينة والديون؟ | منطق محاسبي في مشروعين مستقلين | تحديد مالك كل حدث واتجاه API/export لمنع القيد المزدوج؛ تصحيحات ERP المحلية ليست نشرًا أو تكاملًا |
| ما سياسة تقسيم الشهر والرانك؟ | الشرائح تتوقف عند فترة جزئية/صلاحية غير مثبتة؛ استحقاق العمولة يحتاج تسوية فعلية | سياسة شركة مؤرخة ومصدر منصة معتمد؛ لا استنتاج رانك من طلبات مجموعة ناقصة |
| كيف يصنف التعديل السالب غير العمولة؟ | `Cr 5301` حاليًا | ربط الغرامة/التلفيات بحساب الاسترداد أو التكلفة الموافق عند اعتماد التغيير |
| هل تُلزم رسوم جاهز بهوية وحساب منصة وتفرد عليهما؟ | المرجع فريد، لكن الهوية اختيارية والقيمة قابلة للإدخال | تعريف مفتاح التفرد والاستثناءات؛ لا ادعاء منع تكرار الرسوم لكل حساب حاليًا |
| ما سياسة التشغيل والنسخ الاحتياطي؟ | نشر main تلقائي، وcheckpoint على نفس السيرفر | staging واعتماد إنتاج، وجهة نسخ خارجية وتشفير واحتفاظ واختبار استعادة؛ كلها أعمال معلقة |

وجود قرار محاسبي لا يثبت معالجة ضريبية أو صحة أرصدة إنتاج. هذه الحزمة تحفظ قواعد المشروع ومواضع عدم الحسم، ولا تستبدل مراجعة المالية للمستندات.
