# Endpoint index — 0.10.0 API / 1.0-A

Generated by `python3 tools/api_inventory.py`; built-in admin-only OpenAPI: `/openapi/v1.json`.

Permissions below are minimum route gates; existing handler checks, company scope and maker-checker also apply. Lists use `period=yyyy-MM`, ranges `from/to=yyyy-MM-dd`; opt-in `page>=1`, `pageSize<=200`, `q`, `sort=field|-field` return `{items,total,page,pageSize}`. Without `page`, legacy responses are unchanged.

Review actions stay on their existing routes. `/promissory-notes` is the document archive; `/finance/features/promissory-notes` is its feature setting. Deprecated routes remain callable.
