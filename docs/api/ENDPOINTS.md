Lists use `period=yyyy-MM`, ranges `from/to=yyyy-MM-dd`; opt-in `page>=1`, `pageSize<=200`, `q`, `sort=field|-field` return `{items,total,page,pageSize}`. Without `page`, legacy responses are unchanged.

Review actions stay on their existing routes. `/promissory-notes` is the document archive; `/finance/features/promissory-notes` is its feature setting. Deprecated routes remain callable.
